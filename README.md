# Salah Asif Parbhulkar Portfolio

A modern AI Engineer portfolio built using:

- Next.js 15
- TypeScript
- Tailwind CSS 4
- Motion (Framer Motion)
- Lucide React

## About

This portfolio showcases:

- AI & Machine Learning experience
- LLM Systems
- Agentic Workflows
- FastAPI Development
- Model Benchmarking
- Research Projects
- Hackathon Achievements
- Certifications

## Features

### UI & UX

- Modern glassmorphism design
- Animated AI-themed loading screen
- Responsive mobile-first layout
- Smooth scroll navigation
- Interactive certification previews
- Dynamic experience timeline
- Animated skill progression
- Professional project showcase

### Technical

- TypeScript
- App Router
- Component-based architecture
- Motion-powered animations
- Reusable data-driven content structure
